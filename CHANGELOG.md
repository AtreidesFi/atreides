# Changelog

## 25 November 2026

- Added the MIT license to the public tree and to both SDK packages.
- The CLI reads the current Atreides environment variables in both SDKs.
- Updated the onboarding and agent guides for invite-only access, scoped MCP trading and the hosted-bot rollout.

## 24 November 2026

- The Python SDK now installs and imports as `atreides`. The TypeScript release package is `@atreides/sdk`. Both SDKs provide the `atreides` CLI.
- The [SDK quick-start](docs/api/guides/sdk.md) uses the renamed packages and shows how to read markets, authenticate, and test an order.
- Added the [Router on your size API guide](docs/api/guides/router-on-your-size.md), including request limits, planner outputs and how to read the benchmark.
